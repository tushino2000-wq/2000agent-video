# Быстрый старт видеогенератора

## 🚀 Локальный запуск (для разработки)

### Способ 1: Напрямую в браузере (без Node.js)

1. Откройте файл `index.html` в браузере (двойной клик)
2. Введите пароль: `tushino2000`
3. Перейдите в "Настройки API" и введите ваш API ключ
4. Начните создавать видео!

### Способ 2: С Node.js сервером (рекомендуется)

```bash
# Установка зависимостей
npm install

# Запуск сервера
npm start

# Откройте http://localhost:3000 в браузере
```

## 🔐 Учетные данные

- **Пароль приложения:** `tushino2000`
- **API ключ:** Получите на https://kie.ai/dashboard

## 📋 Основной функционал

### Создать видео
1. Напишите описание сцены (до 4000 символов)
2. (Опционально) Загрузите референсное изображение
3. Выберите:
   - Видеомодель (Grok, MiniMax, Seedance, Kling и т.д.)
   - Длительность (5-30 сек)
   - Соотношение сторон (16:9, 9:16, 1:1 и т.д.)
   - Разрешение (480p-4K)
4. Нажмите "Создать видео"
5. Следите за прогрессом в карточке "Текущее задание"

### История
- Просмотр всех созданных видео
- Информация о статусе каждого видео
- Фильтр по моделям

### Настройки API
- Введите и сохраните API ключ
- Просмотр справки по моделям
- Управление звуковыми уведомлениями

## 🎨 Интерфейс

### Левая колонка
- Меню навигации
- Кнопка выхода в нижней части

### Центральная колонка
- Основной контент (формы, история)
- Раскрывается при сворачивании боковых

### Правая колонка
- Мини-история последних 5 задач
- Галерея созданных видео
- Можно изменять размер (перетаскивание за resizer)

### Функции управления
- **Сворачивание:** Нажмите стрелку в заголовке колонки
- **Изменение размера:** Перетащите вертикальную полоску справа
- **Мобильное меню:** Используйте кнопку "бургер" на мобильных устройствах
- **Тема:** Переключайте темную/светлую тему кнопкой луны/солнца

## 💾 Локальное хранилище

Приложение автоматически сохраняет:
- API ключ
- История генерации
- Текущую задачу
- Тему оформления
- Состояние звука

Все данные хранятся в `localStorage` вашего браузера.

## 🔊 Уведомления

### Toast-сообщения
- Появляются в углу экрана
- Автоматически исчезают через 4 секунды
- Три типа: успех (✓), ошибка (✕), информация (ℹ)

### Звуковые сигналы
- Короткий "бип" при отправке видео
- Два "бипа" при успешном завершении
- Отключаются в настройках

## 🐛 Решение проблем

### Пустая форма при загрузке
- Перезагрузите страницу (F5)
- Очистите кэш браузера (Ctrl+Shift+Del)
- Проверьте консоль (F12 → Console)

### API ключ не сохраняется
- Убедитесь, что ключ верный
- Проверьте, что не используется приватный режим браузера
- Попробуйте другой браузер

### Звук не работает
- Проверьте громкость браузера
- Убедитесь, что звук включен в настройках
- На мобильных: выключите режим "без звука"

### Видео не генерируется
- Проверьте подключение к интернету
- Убедитесь, что API ключ действителен
- Попробуйте с меньшей длительностью/разрешением
- Проверьте консоль браузера на ошибки

## 🚀 Деплой на Render.com

1. Создайте репозиторий на GitHub
2. Push всех файлов
3. Зайдите на https://render.com
4. Создайте новый Web Service
5. Подключите репозиторий
6. Build: `npm install`
7. Start: `npm start`
8. Добавьте Environment Variable: `NODE_ENV=production`
