🎬 ВИДЕОГЕНЕРАТОР AI - ИНСТРУКЦИЯ ДЛЯ ПЕРВОГО ЗАПУСКА
========================================================

🚀 ВАРИАНТ 1: БЕЗ NODE.JS (САМЫЙ ПРОСТОЙ)
===========================================

1. Откройте папку: C:\Users\USER\Documents\open code
2. Найдите файл: index.html
3. Двойной клик на index.html
4. Браузер откроется автоматически
5. Введите пароль: tushino2000
6. Нажмите "Войти"
7. Перейдите в "Настройки API"
8. Введите ваш API ключ (получите на https://kie.ai)
9. Нажмите "Проверить и сохранить"
10. Готово! Начните создавать видео!

⚡ ВАРИАНТ 2: С NODE.JS (РЕКОМЕНДУЕТСЯ)
=========================================

Шаг 1: Установка Node.js
-------------------------
1. Откройте https://nodejs.org
2. Скачайте LTS версию
3. Установите с параметрами по умолчанию
4. После установки перезагрузите компьютер

Шаг 2: Открытие терминала
--------------------------
1. Откройте папку: C:\Users\USER\Documents\open code
2. Кликните на путь сверху в файловом менеджере
3. Введите: cmd
4. Нажмите Enter (откроется черная командная строка)

ИЛИ альтернативно:
1. Нажмите Win + R
2. Введите: cmd
3. Введите: cd C:\Users\USER\Documents\open code
4. Нажмите Enter

Шаг 3: Установка зависимостей
------------------------------
В черной командной строке введите:
npm install

Это займет 1-2 минуты. Ждите завершения.

Шаг 4: Запуск сервера
---------------------
После завершения install, введите:
npm start

Вы увидите:
Server running at http://localhost:3000
Environment: development

Шаг 5: Открытие в браузере
--------------------------
1. Откройте браузер (Chrome, Firefox, Edge и т.д.)
2. В адресной строке введите: http://localhost:3000
3. Нажмите Enter
4. Приложение откроется!

Шаг 6: Первый вход
-----------------
1. Введите пароль: tushino2000
2. Нажмите "Войти" или Enter

Шаг 7: Настройка API ключа
--------------------------
1. Нажмите в левом меню "Настройки API"
2. Введите ваш API ключ
3. Нажмите "Проверить и сохранить"
4. Готово!

Шаг 8: Создание первого видео
-----------------------------
1. Нажмите "Создать видео" в меню
2. Напишите описание сцены (например: "Красивый закат над горами")
3. Выберите видеомодель (рекомендуется: Seedance 2)
4. Выберите длительность: 10 сек
5. Оставьте остальное как есть
6. Нажмите "Создать видео"
7. Ждите генерации (может быть 1-10 минут)
8. Вы получите уведомление, когда видео готово!

💾 ВАРИАНТ 3: ОБЛАЧНЫЙ ДЕПЛОЙ (RENDER.COM)
==========================================

Это немного сложнее, но приложение будет доступно всем по ссылке!

1. Создайте аккаунт на GitHub (если еще нет)
2. Создайте новый репозиторий
3. Push все файлы туда
4. Зайдите на render.com
5. Создайте новый Web Service
6. Подключите ваш GitHub репозиторий
7. Build Command: npm install
8. Start Command: npm start
9. Нажмите Deploy
10. Готово! Ваше приложение в интернете!

🐛 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
============================

Ошибка: "Невозможно подключиться"
  → Убедитесь, что терминал все еще открыт
  → Введите npm start еще раз
  → Перезагрузите браузер (F5)

Ошибка: "Invalid API key"
  → Проверьте правильность ключа
  → Скопируйте еще раз с kie.ai
  → Убедитесь, что нет пробелов

Ошибка: "File not found" при открытии index.html
  → Используйте Вариант 2 (Node.js)
  → Откройте через npm start

Видео не генерируется
  → Проверьте API ключ
  → Уменьшите длительность (5 сек)
  → Попробуйте другую модель
  → Проверьте консоль (F12)

❓ ВОПРОСЫ И ОТВЕТЫ
===================

Q: Как долго генерируется видео?
A: Обычно 1-10 минут в зависимости от модели и параметров

Q: Какая модель самая быстрая?
A: Seedance 2 Fast - генерирует за 1-3 минуты

Q: Какая модель самая качественная?
A: Kling 3.0 - лучшее качество, но медленнее

Q: Можно ли отменить генерацию?
A: Нет, но следующее видео перезапишет текущее

Q: Где хранятся мои видео?
A: На серверах KIE, ссылка приходит при готовности

Q: Безопасен ли мой API ключ?
A: Да, он шифруется и хранится локально в браузере

Q: Могу ли я использовать на нескольких устройствах?
A: Да, если используете облачный деплой (Render.com)

Q: Нужно ли платить?
A: Платите только за генерацию видео на kie.ai
