## 🚀 Как запустить

### Способ 1: Браузер (без Node.js)
```
1. Двойной клик на index.html
2. Пароль: tushino2000
3. Готово!
```

### Способ 2: Node.js (рекомендуется)
```bash
npm install
npm start
# Откройте http://localhost:3000
```

### Способ 3: Render.com (облако)
```
1. Push на GitHub
2. Создайте Web Service на render.com
3. Build: npm install
4. Start: npm start
5. Готово!
```
