# ANYCHAT

Адаптивный веб-чат для ANYMODEL с выбором моделей, пользовательскими моделями и вложениями. Работает на компьютере и телефоне, разворачивается на Netlify.

История автоматически сохраняется в браузере после каждого сообщения. Отдельный диалог можно удалить крестиком рядом с его названием, всю историю — кнопкой **Очистить**.

## Локальный запуск

1. Установите Node.js 20 или новее.
2. Выполните `npm install`.
3. Создайте `.env` по примеру `.env.example` и вставьте ключ ANYMODEL.
4. Запустите `npm run dev`.

Важно: используйте `npm run dev`, а не только `vite`, потому что запросы идут через локальную Netlify Function.

## Развёртывание на Netlify

1. Загрузите папку проекта в GitHub/GitLab или импортируйте её через Netlify CLI.
2. В Netlify выберите **Add new site > Import an existing project**.
3. Build command и Publish directory будут считаны из `netlify.toml`.
4. Откройте **Site configuration > Environment variables**.
5. Добавьте `ANYMODEL_API_KEY` со своим ключом.
6. Добавьте `ANYMODEL_API_URL=https://anymodel.org/v1`. Приложение автоматически добавит `/chat/completions` к базовому адресу `/v1`.
7. Запустите Deploy.

После публикации сайт доступен с телефона и компьютера через любой интернет. Ключ в переменной Netlify остаётся на сервере и не показывается посетителям.

Ключ и API URL также можно ввести непосредственно в окне **API ключ** на сайте. Они сохраняются в локальном хранилище браузера и остаются после закрытия вкладки, пока пользователь не нажмёт **Удалить** или не очистит данные сайта. Не сохраняйте ключ на чужом устройстве. Если в Netlify уже заданы серверные переменные, они имеют приоритет.

## API и файлы

Сервер ожидает OpenAI-совместимый endpoint `/v1/chat/completions`. Изображения передаются как `image_url` в формате data URL. Текстовые и офисные файлы кодируются и передаются в контексте запроса; фактическая поддержка формата зависит от выбранной модели и ANYMODEL. За одно сообщение можно прикрепить до 4 файлов суммарным размером до 3 МБ.

Публичный сайт `anymodel.xyz` сообщил о закрытии сервиса и не публикует подтверждённый API endpoint. Поэтому URL намеренно не зашит в код: возьмите его из кабинета или документации того ANYMODEL-провайдера, который выдал ключ. Не добавляйте настоящий API-ключ в исходный код или Git.
