# AI Video Generator

Веб-приложение для генерации видео с помощью различных AI моделей.

## Возможности

- ✨ Современный трехколоночный интерфейс
- 🎬 Поддержка множества видеомоделей (Grok, MiniMax, Seedance, Kling, Wan, PixVerse, HappyHorse)
- 🖼️ Загрузка референсных изображений
- ⏱️ Мониторинг статуса генерации в реальном времени
- 🔔 Система уведомлений с звуковыми сигналами
- 🌓 Темная/светлая тема
- 📱 Полностью адаптивный дизайн
- 🔐 Защита паролем
- 💾 Локальное хранение истории

## Установка

### Локальная разработка

1. Клонируйте репозиторий:
```bash
git clone <your-repo-url>
cd video-generator-ai
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env`:
```bash
cp .env.example .env
```

4. Запустите сервер:
```bash
npm start
```

5. Откройте браузер: `http://localhost:3000`

### Деплой на Render.com

1. **Создайте новый Web Service на Render.com**

2. **Подключите ваш Git репозиторий**

3. **Настройте Build и Deploy:**
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment:** Node

4. **Добавьте переменные окружения (Environment Variables):**
   ```
   NODE_ENV=production
   BASE_URL=https://api.kie.ai/v1
   ```

5. **Нажмите "Create Web Service"**

Render.com автоматически развернет приложение и предоставит публичный URL.

## Использование

### Первый вход

1. При первом открытии приложения введите пароль: `tushino2000`
2. Перейдите в раздел "Настройки API"
3. Введите ваш API ключ от KIE и нажмите "Проверить и сохранить"

### Создание видео

1. Перейдите в раздел "Создать видео"
2. Введите описание сцены (до 4000 символов)
3. (Опционально) Загрузите референсное изображение
4. Выберите модель, длительность, соотношение сторон и разрешение
5. Нажмите "Создать видео"
6. Следите за прогрессом в карточке "Текущее задание"
7. Получите уведомление по завершении генерации

### Функции интерфейса

- **Сворачивание колонок:** Используйте стрелки в заголовках колонок
- **Изменение размера правой колонки:** Перетаскивайте resizer (вертикальная полоса)
- **Мобильное меню:** Нажмите на иконку бургера на мобильных устройствах
- **Переключение темы:** Используйте иконку луны/солнца

## Безопасность

- Пароль хранится локально
- API ключ не передается на сервер (если используете прямые API вызовы)
- Все пользовательские данные обрабатываются через `escapeHtml()`
- HTTPS рекомендуется для продакшена

## Настройки

### Изменение пароля

Отредактируйте константу в `app.js`:
```javascript
const CONFIG = {
    PASSWORD: 'ваш_новый_пароль',
    // ...
};
```

### Изменение интервала polling

Отредактируйте константу в `app.js`:
```javascript
const CONFIG = {
    POLLING_INTERVAL: 15000, // миллисекунды
    // ...
};
```
